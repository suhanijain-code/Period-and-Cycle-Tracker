# Period & Cycle Tracker



## Problem Statement

Keeping track of periods manually may not be an easy task. Women and girls may have difficulties recalling the date of the last period, cycle length or period length.
Period & Cycle Tracker aims at providing an easy platform for a woman to enter the relevant cycle details and get information regarding the expected period and current cycle day. The user will also be able to view their past cycle records.

## Scope of the Project

The scope of the project includes:

1. Entering the date of the last period

2. Entering cycle length

3. Entering the period length

4. Validating the entries

5. Calculating the next period

6. Calculating the current cycle day

7. Storing the cycle records in a local file

8. Viewing past cycle records

9. Providing a graphical interface for use

The project is designed for cycle tracking and record management purposes only. It does not involve medical diagnosis and should not be used as a medical tool.



## Target Users
The target users of the application are:

1. Women and girls who wish to keep track of their cycle.

2. Women and girls who wish to store their cycle records digitally.

3. Women and girls looking for a desktop cycle tracking application.



## High-level Features

The features of the application include:

1. Adding a new cycle

2. Validating the data entry

3. Calculating the next period

4. Determining the current cycle day

5. Saving the cycle records

6. Viewing past cycle records

7. Using a graphical interface
